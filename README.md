# Moore Strikes

A top-down arcade bowling game built with plain HTML/CSS/JS and canvas.

## Features
- Full 10-frame bowling with real scoring (strikes, spares, 10th-frame bonus rolls)
- Real pin-on-pin and ball-on-pin physics (mass, momentum, collisions)
- Slide the ball left/right along the foul line before you throw
- Adjustable hook/curve dial that breaks the ball late down the lane, like a real hook
- Retro arcade visual style

## Play
Open `index.html` in any modern browser. No build step or dependencies required.

## Controls
- Drag the ball left/right to position it
- Set the hook dial (left = hooks left, right = hooks right, center = straight)
- Swipe up from the ball to bowl — the length of the swipe sets the power
